# 오늘저금 · Daily Piggy

**하루 자유 예산을 가상의 저금통처럼 쌓아 보며 소비와 목표를 관리하는 Apps in Toss 미니앱입니다.**

[프로필로 돌아가기](https://github.com/hyesun5464)

## 해결하려는 문제

작은 소비가 쌓일 때 남은 자유 예산을 직관적으로 파악하고, 원하는 물건을 위해 얼마나 더 모아야 할지 확인할 수 있는 도구를 만들고자 했습니다.

## 사용 흐름

1. 하루 자유 예산을 설정합니다.
2. 날짜가 지나면 해당 예산이 가상 잔액에 적립됩니다.
3. 소비한 금액을 직접 기록해 잔액에서 차감합니다.
4. 목표 금액과 현재 잔액을 비교하며 진행 상황을 확인합니다.

## 주요 기능

- 일일 예산 설정과 다음 날 적용되는 예산 변경
- 한국 날짜 기준 자동 적립과 중복 적립 방지
- 소비 추가·수정·삭제 및 초과 소비 확인
- 목표 등록, 진행 상황 확인, 구매 처리
- 날짜별 내역과 잔액에 따라 동전이 쌓이는 유리 저금통 시각화

실제 돈을 보관하거나 이체하는 서비스가 아닙니다. 계좌·카드 연동 없이 사용자가 기록하는 가상 예산을 다룹니다.

## 제작 시 중요하게 본 점

| 고민 | 설계 방향 |
|---|---|
| 며칠 만에 다시 열어도 잔액이 맞아야 합니다. | 경과한 날짜를 정산하고 같은 날의 중복 적립을 방지합니다. |
| 소비를 잘못 적었을 때 고치기 쉬워야 합니다. | 소비 수정·삭제와 실행 취소 흐름을 제공합니다. |
| 숫자만으로는 쌓이는 느낌이 약합니다. | 잔액에 따라 내부 동전 더미가 달라지는 투명 저금통으로 표현합니다. |
| 가상 잔액을 실제 예금으로 오해할 수 있습니다. | 온보딩과 이용 안내에서 가상 예산임을 알립니다. |

## 맡은 역할

개인 프로젝트로 서비스 기획, 화면과 사용 흐름 결정, AI 도구를 활용한 구현 및 사용 점검을 진행합니다.
